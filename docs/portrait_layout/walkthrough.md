# 9:16縦長レイアウト（1人2行）の実装完了

縦長表示（9:16）向けにドライバー1人あたりの行を2段で表示するレイアウトの実装が完了しました。

## 変更内容 (Changes Made)

1. **設定項目の追加**
   - `public/settings.html` に、行数設定「縦型 (1人2行)」(内部値: `18`) を追加しました。
2. **モードの切り替え処理**
   - `public/js/display.js` にて、行数設定が `18` の場合に `body` 要素へ `mode-portrait` クラスを付与するロジックを追加しました。
3. **CSS Gridを利用した2段レイアウトの実装**
   - `public/css/display.css` の末尾に `mode-portrait` 専用のスタイルを追加しました。
   - `table.results-table tr` に対して `display: grid` を指定し、各セルを `grid-column` と `grid-row` を用いて再配置しました。
   - **1段目:** ステータス、順位、ゼッケン、Name、Kana、R1/P3/P4、R1/P1、Best
   - **2段目:** 車番、Memo、R2/P4、R2/P2、Diff

## かな表記の対応
NameとKanaは、`grid-column`の設定によって横並び（Nameのすぐ右側）に配置されるように調整しました。設定画面で「かなを表示」をOFFにすると、Kanaの列（`.col-kana`, `.cell-kana`）は非表示になり、その分のスペースには空きができますが、Name領域が大きく使える状態になります。

## 動作確認 (Validation)

ローカル環境や実機等で、以下の手順でご確認いただけます。

1. **設定の変更**: `/settings.html` にアクセスし、「表示レイアウト」＞「表示サイズ」で「縦型 (1人2行)」を選択して保存してください。
2. **表示画面の確認**: `/display.html` にアクセスし、ウィンドウサイズを縦長（例: 1080×1920）に変更してください。
3. ドライバーの行が2段レイアウトで綺麗に表示され、各タイム列やエフェクトが正常に作動することを確認できます。
