# タスク: DB切り替え・i18n・リザルト画面修正

## 要件

### 1. results-overview.html の色合い修正
- ライトテーマのページでダークテーマ用の `ghost-button` スタイルが適用されており、ボタンのテキストが見にくい
- ライトテーマに合った色合いに修正する

### 2. レースコントロール画面の日本語化
- 設定画面でシステム設定・表示言語を日本語にした場合、レースコントロール画面(control.html)の各ボタン等を日本語に切り替える
- 言語設定は API `/api/settings` で取得される `language` フィールドを使用
- 対象: ヘッダー、セクションタイトル、ボタンラベル、プレースホルダーテキスト等

### 3. データベース切り替え機能
- `data` フォルダ内の `.db` ファイルを一覧表示し、選択して切り替えられるようにする
- 新規作成時のDB名は `soapbox-YYMMDD-HHMM.db` 形式
- リセット時も同様の命名規則でDBを新規作成
- 設定画面にDB切り替えUIを追加
